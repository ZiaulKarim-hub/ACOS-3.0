# Taxonomy — Property Sale Data Room

Folder structure for the final property-sale data room. Real-estate-focused
(no loan documents — those are not the buyer's concern in a property sale).

Categories align with `references/checklist_property_sale.md`.

## Top-Level Folders

```
[DataRoomName]/
├── 01_Property_Overview/
├── 02_Title/
├── 03_Survey/
├── 04_Environmental/
├── 05_Property_Condition/
├── 06_Zoning_and_Entitlements/
├── 07_Permits_and_Code_Compliance/
├── 08_Leases_and_Tenant_Materials/
├── 09_Operating_Financials/
├── 10_CapEx_History_and_Plan/
├── 11_Service_Contracts/
├── 12_Insurance/
├── 13_Real_Estate_Taxes/
├── 14_Utilities/
├── 15_Marketing_and_Comparables/
├── 16_REO_Post_Foreclosure/  # <-- only populated if applicable
├── 17_Property_Sale_Transaction/
├── 99_Index_and_QA/
```
