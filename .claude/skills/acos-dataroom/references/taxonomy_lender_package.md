# Taxonomy — Lender Package Data Room

Folder structure for a lender-package (takeout / refinance pitch) data room.
Skews toward what a CRE underwriter at the takeout lender will need —
narrative + financials + market support + risk story.

Categories align with `references/checklist_lender_package.md`.

## Top-Level Folders

```
[DataRoomName]/
├── 01_Executive_Summary/
├── 02_Loan_Performance_History/
├── 03_Current_Loan_Snapshot/
├── 04_Borrower_and_Sponsor_Profile/
├── 05_Sponsor_Financial_Strength/
├── 06_Property_Profile/
├── 07_Property_Financial_Performance/
├── 08_Capital_Stack_and_Pro_Forma/
├── 09_Updated_Valuation_and_Market/
├── 10_CapEx_History_and_Plan/
├── 11_Refinance_Thesis_and_Takeout/
├── 12_Proposed_Terms/
├── 13_Risk_Mitigants_and_Stress_Tests/
├── 14_Third_Party_Reports/
├── 15_Title_and_Insurance/
├── 16_Operations_and_Management/
├── 17_Tax_and_Regulatory/
├── 99_Index_and_QA/
```
