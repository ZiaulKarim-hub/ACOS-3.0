# Taxonomy — Foreclosure Auction Data Room

Folder structure for a foreclosure / trustee sale data room. Combines
procedural compliance file (defending the sale) with bidder package
(supporting bidder evaluation).

Categories align with `references/checklist_foreclosure_auction.md`.

## Top-Level Folders

```
[DataRoomName]/
├── 01_Default_and_NOD/
├── 02_Acceleration_and_Demand/
├── 03_Notice_of_Sale/
├── 04_Junior_and_Required_Party_Notices/
├── 05_Borrower_and_Guarantor_Notices/
├── 06_Court_Filings_Judicial/    # <-- only populated for judicial foreclosures
├── 07_Trustee_Sheriff_Procedures/
├── 08_Title_at_Sale/
├── 09_Asset_Bidder_Package/
├── 10_Occupancy_and_Eviction/
├── 11_Redemption_Rights_Analysis/
├── 12_Payoff_and_Bid_Calculation/
├── 13_Auction_Day_Logistics/
├── 14_Post_Sale_Documents/
├── 15_Compliance_Checklist/
├── 99_Index_and_QA/
```
