# User Guide Writing Skill

## Purpose

This skill provides structured guidance for creating user documentation that is clear, helpful, and accessible to the target audience.

## When to Use

Apply this skill when:
- Creating end-user documentation
- Writing help content
- Creating onboarding guides
- Writing tutorials
- Documenting features for users

## Skill Protocol

### Phase 1: Audience Analysis

1. Identify your audience (who, technical level, what they know, what they're trying to accomplish)
2. Define scope (topics, detail level, exclusions)

### Phase 2: Structure Planning

1. Organize content (logical flow, progressive complexity, task-based)
2. Plan sections (getting started, core features, advanced, troubleshooting)

### Phase 3: Writing

1. Use simple language, be concise, use active voice, one idea per sentence
2. Show, don't just tell: include examples, screenshots, step-by-step instructions

### Phase 4: Review

1. Can a new user follow this? Are steps complete? Are examples helpful?
2. Follow your own guide, have someone else try it, fix gaps

## Writing Guidelines

| Do | Don't |
|----|-------|
| Use "you" | Use "the user" |
| Use active voice | Use passive voice |
| Use simple words | Use jargon unnecessarily |
| Be specific | Be vague |
| Use present tense | Use future tense |

## Quality Checklist

- [ ] Audience clearly defined
- [ ] Topics logically organized
- [ ] Simple language used
- [ ] Technical terms explained
- [ ] Steps are numbered
- [ ] Examples provided
- [ ] Troubleshooting included
- [ ] Spelling and grammar checked
- [ ] All links work
- [ ] Consistent formatting
