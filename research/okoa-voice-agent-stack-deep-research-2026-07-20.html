Recommendation (bottom line)

For OKOA — an institutional / high-net-worth (HNW) real-estate lender — adopt the brand-safe stack (Stack B). A confidently wrong answer about a fund, its terms, or returns is a securities-marketing and reputational risk, not merely a UX glitch. That risk outranks a few cents per minute of savings.

PRIMARY PICK — Stack B (brand-safe institutional):
  • Durable agent app (brain-host + memory): VoltAgent or Convex Durable Agents (TypeScript, durable + built-in memory), deployed on Cloudflare so that Durable Objects provide crash-durability and per-visitor cross-session memory in one layer.
  • Telephony / voice (phone + speech-to-text + text-to-speech): Retell AI — managed, ~600 ms latency, HIPAA-standard, all-in $0.11–0.25/min.
  • AI model (the brain): Claude Haiku 4.5 ($1.00 / $5.00 per 1M tokens) as default, escalating to Claude Sonnet 4.6 ($3.00 / $15.00) for any factual claim about the firm, funds, or terms. A text checkpoint at the Claude layer lets the system ground, filter, or refuse before anything is spoken.
Satisfies: no Python; phone-call form-fill; cross-session memory; crash-durability; institutional brand-safety.
BUDGET ALTERNATIVE — Stack A (cheapest + fastest, "boss-lens"):
  • Durable agent app: Rig (Rust) for a fast-language brain the boss favours — or a TypeScript durable framework (Convex / VoltAgent) for less do-it-yourself work.
  • Telephony / voice: Bland (flat ~$0.09/min bundled) or Vapi ($0.05/min platform fee).
  • AI model: Gemini 2.5 Flash-Lite ($0.10 / $0.40) or Groq + Llama 3.3 70B (~180 ms time-to-first-token — the fastest measured).
Trade-off / warning: the cheapest models drop the Claude brand-safety checkpoint. For a regulated lender this is a real risk. If cost is the hard constraint, run Stack A but route every factual claim through a Claude check before it is spoken — a partial compromise.

Two facts that should reframe the debate: (1) "No Python" is a free win — many TypeScript options exist, plus production-viable Rust (Rig). (2) Rust's speed helps least where the boss expects most: language speed is the smallest slice of voice latency, and there is no mature Rust voice/telephony framework, so the phone layer is a managed vendor regardless of language.

1. Executive Summary

OKOA wants a voice agent on its public marketing website that (a) answers visitor questions accurately, (b) lets a visitor call from a phone and fill out a form by voice, (c) remembers returning callers across sessions, and (d) survives crashes. The boss's stated priorities are fastest + cheapest, a preference for fast languages (Rust), and a reluctance to use Python.

A voice phone agent has five logical jobs: a durable agent app (manager + memory), telephony (the phone line), speech-to-text (STT, the "ears"), an AI model (LLM, the "brain"), and text-to-speech (TTS, the "mouth"). Managed voice platforms (Retell, Vapi, Bland) bundle telephony + STT + TTS into one product, which collapses the visible building blocks to roughly three: durable agent app + managed voice platform + AI model.

Durability vs. memory are distinct: durability = surviving a crash within one run; memory = recalling a returning caller across separate calls. Both save state to storage, and Cloudflare Durable Objects deliver both — which is why the two concepts blur.

The decisive variable is the AI model, not the programming language. No-Python is easily achieved. The genuine trade-off is cheapest-model (Gemini Flash-Lite / Groq) versus brand-safe-model (Claude with a pre-speech text checkpoint). For an institutional/HNW audience, brand-safety wins.
