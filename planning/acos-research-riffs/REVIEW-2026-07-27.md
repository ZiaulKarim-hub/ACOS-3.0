## Robustness roadmap (structural themes, ranked)

### R1. Crash-consistent, atomic on-disk state

- **What:** Make writeJson atomic (tmp + renameSync) in util.ts — covering manifest, coverage, panel, and tree in one move — apply the same to both dossier rewrite sites in claims.ts, extend the loadManifest corruption hardening to tree.json, preserve rejected lines in sidecars instead of deleting them, and remove the write-on-read in evaluateGate so query commands never mutate.
- **Value:** Eliminates an entire class of findings (room.ts:69, tree.ts:35, claims.ts:174/399, coverage.ts:204/riff.ts:258) in an environment that demonstrably hard-kills sessions at token limits; a torn write currently ranges from a 500ing room to silently cementing an empty tree over the whole outline.
- **Cost:** Small: one util change plus a call-site sweep and two dossier-rewrite conversions; the evaluateGate persist flag is a one-parameter refactor.

### R2. Pid-bound liveness protocol for the three-daemon seam

- **What:** Give every runtime artifact (room-live.status, room-live.lock, room.port, room-live.out) an owner: stamp writer pid+ts, trust beacons only when the lock names a live process, unlink stale beacons before spawn, open logs append-mode with per-run delimiters, re-assert lock ownership in the poll loop, refuse init --force while a live room/responder exists, and fail fast with a real reason on ENOENT binaries and all-dead pools.
- **Value:** Closes the whole stale/dual-daemon cluster (riff.ts:130/119, session.ts:159, riff-live.ts:59/116/455/470, riff.ts:892) — currently the CLI can report the wrong daemon's state, corrupt its own diagnostics, and run two responders double-billing every click.
- **Cost:** Moderate: a shared session-runtime helper (readLock/isLive/claimBeacon) used by riff.ts, riff-live.ts, and initSession, plus a handful of targeted call-site changes.

### R3. Schema validation at every LLM-authored trust boundary

- **What:** One validate-payload helper applied uniformly where model-authored JSON enters the engine: coverage init/add elements, panel set/add seats (before persistence), tree apply groups, claim id shape and tier normalization at ingest, slug path-safety, and Number.isFinite on every numeric flag (--min/--strong/--limit/--tail/level).
- **Value:** The fix pass proved the pattern (--novel, P12) but applied it patchily; the gaps let a key typo brick the coverage gate, a NaN silently disarm the abstain guardrails, and a string tier pass the primary-source gate — all fail-unsafe directions in the trust machinery (riff.ts:380/690, panel.ts:57/131/207, tree.ts:138, claims.ts:541/249, riff-live.ts:487).
- **Cost:** Low-medium: mostly mechanical guards at existing call sites; the payoff-per-line is the highest in this list.

### R4. Truth semantics of the claims trust chain

- **What:** Rework the dedup/corroboration primitives as one unit: ordered-sequence sameNumbers, negation-parity guard, best-match (not first-match) dedup targeting, conflict-aware corroboration that excludes disputants and surfaces conflicting_ids, tier normalization shared by stamp and gate — then plumb the outputs (conflicts, corroborating_sources, numeric_unprimaried_ids) through riff.ts ask and into SKILL.md's protocol with claims-lab fixtures for each.
- **Value:** Every one of the empirically confirmed high findings lives here (claims.ts:554/237/123/232/541): today a contradicted figure reads verified, a negation upgrades the claim it refutes, and a correction can never merge into the claim it confirms — the founding failure class of the skill.
- **Cost:** Medium: ~5 coordinated changes in claims.ts plus CLI/doc plumbing and fixtures; the primitives are small and already colocated.

### R5. Close the live room into the delivery/eval loop

- **What:** Treat chair-inbox.jsonl and room-turns.jsonl as first-class delivery: markSurfaced (or corpus-matcher scan) over live turns for figures-primary-sourced, count chair messages in research-reached-the-reader, tag synthetic failure turns err:true and exclude them from spokeBefore and transcript replay, and fence/flatten the DISCUSSION replay like chair text.
- **Value:** The flagship interaction channel currently escapes the I9 hard-fail backstop entirely, gets described as 'no conversation took place', pollutes grounded prompts with error text, and carries the unfenced half of M16 (report.ts:429/467, riff-live.ts:297/211) — the eval is only trustworthy for the channel users use least.
- **Cost:** Medium: a shared corpus-id matcher already exists in citationAudit; the rest is a Turn schema field and two eval branches.

### R6. Single source of truth for adapter/page and gate contracts

- **What:** Extract a shared computeGate used by evaluateGate and buildRoomState; actually send the data-driven labels room.html now consumes (vote label_a/label_f, vote_label, research_label); define a monotonic timeline contract (fallback-tagged prefix + turns_total counter) between adapter and page; enumerate the room.html relabel allowlist in ARCHITECTURE.md.
- **Value:** The switchover bug, the AGAINST/FOR mislabeling, the fabricated-seat-speech display, and the future gate-desync risk (room.ts:356/416/369/81/352, room.html:156) are all symptoms of two implementations of one contract drifting; fixing the contract fixes them as a family and keeps IC upstream flow safe.
- **Cost:** Medium: one exported helper, ~6 adapter fields, and a page-side detector rebuilt once (with the timeline cap done at the same time).

### R7. Test the failure machinery, not just the happy path

- **What:** Cover the M10 worker-death state machine (magic DIE prompt, RIFF_JOB_TIMEOUT_MS watchdog run, post-warmup giveup), assert the load-bearing worker argv and multi-event/error streams from the stub, add the I42 grounding and routeToSeat assertions, test the same-origin accept branch, race every SSE read, install a signal-safe reaper, and make file-reads-under-test tolerant.
- **Value:** The fix pass's largest new code (~80 lines of worker-failure handling) ships with zero assertions, and the suite's own blind spots (grounding filter, --safe-mode, origin accept) are one-line regressions away from silent cross-seat leaks or a dead chair channel behind 320 green checks (test-riff.ts:1782/1852/97/1211/1128/2247/1772).
- **Cost:** Medium: the STUB_LOG and env-knob infrastructure already exists; most items are one stub feature plus a handful of checks each.
