The complete single-file command-line tool `build/isodate.py`. It is the root product and is itself a testable component: its verifier is the whole-product acceptance against the vision.

## What it must do
**Single responsibility:** Print the requested date/time line to stdout and return the correct exit code for the given argv.

Acceptance criteria:
- No-flag run prints exactly one `YYYY-MM-DD` line and exits 0.
- `--utc --time` prints a UTC `YYYY-MM-DD HH:MM:SS` line and exits 0.
- A bad flag exits non-zero and writes a usage message to stderr.
- `isodate.py` imports only Python standard-library modules.
