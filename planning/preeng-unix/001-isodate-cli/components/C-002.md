# Date/time formatter  (C-002 · part · depth 1)

## What it is
The single shared formatter for default, `--utc`, `--time`, and composed flags. Turns a datetime into the output string.

## What it must do
**Single responsibility:** Turn a datetime plus a `with_time` flag into the correct output string.

Acceptance criteria:
- `format_line(dt, False)` returns `dt`'s date as `YYYY-MM-DD`.
- `format_line(dt, True)` returns `YYYY-MM-DD HH:MM:SS`.
- Deterministic: same `dt` + flag always yields the same string.
- Uses only stdlib `datetime`/`strftime`.

## Output you can see
`software` — a `format_line(dt, with_time)` function in `build/isodate.py` returning a string like `2026-06-05` or `2026-06-05 14:03:09`.

## How to test it
- **Auto-check (software-test):** `PYTHONPATH=planning/preeng-unix/001-isodate-cli/build/tests python3 -m unittest test_isodate.FormatterTests`
- **Human test:** run
  `python3 -c "import sys; sys.path.insert(0,'planning/preeng-unix/001-isodate-cli/build'); import isodate, datetime; dt=datetime.datetime(2026,6,5,14,3,9); print(isodate.format_line(dt, False)); print(isodate.format_line(dt, True))"`
  Pass criteria: line 1 = `2026-06-05`; line 2 = `2026-06-05 14:03:09`.
