# Clock provider  (C-001 · part · depth 1)

## What it is
The single source of "now" for the whole tool. Supplies the current instant as a datetime, and accepts an optional fixed value so tests are deterministic.

## What it must do
**Single responsibility:** Return the current instant as a datetime (local or UTC), honoring an injected fixed clock when provided.

Acceptance criteria:
- `now(fixed=X)` returns exactly `X` (determinism under injection).
- `now(utc=True)` returns a timezone-aware datetime in UTC.
- `now(utc=False)` returns the local current instant.
- Uses only stdlib `datetime`.

## Output you can see
`software` — a `now(utc, fixed)` function in `build/isodate.py`. Calling it with a fixed datetime returns that exact datetime; otherwise the real current instant.

## How to test it
- **Auto-check (software-test):** `PYTHONPATH=planning/preeng-unix/001-isodate-cli/build/tests python3 -m unittest test_isodate.ClockTests`
- **Human test:** run
  `python3 -c "import sys; sys.path.insert(0,'planning/preeng-unix/001-isodate-cli/build'); import isodate, datetime; print(isodate.now(fixed=datetime.datetime(2020,1,2,3,4,5)))"`
  Pass criteria: prints `2020-01-02 03:04:05` exactly (the injected value).
