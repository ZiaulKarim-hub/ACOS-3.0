# Argument parser  (C-003 · part · depth 1)

## What it is
Parses argv into a flags object `{utc, time}`. On unknown/bad flags it emits a usage message on stderr and forces a non-zero exit (argparse contract).

## What it must do
**Single responsibility:** Parse argv into validated flags, or exit non-zero with a usage message on bad input.

Acceptance criteria:
- `parse_args(['--utc'])` yields `utc=True, time=False`.
- `parse_args(['--time'])` yields `time=True`.
- `parse_args([])` yields `utc=False, time=False`.
- An unknown flag raises `SystemExit` with a non-zero code and writes usage to stderr.
- Uses only stdlib `argparse`.
